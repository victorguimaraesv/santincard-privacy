Política de Privacidade — Santin Card

Última atualização: 27 de outubro de 2026

A sua privacidade é importante para nós. Esta Política de Privacidade explica como o aplicativo Santin Card lida com dados e informações.

1. Fonte e Natureza dos Dados

O Santin Card é uma plataforma informativa e de engajamento cidadão que utiliza e exibe dados públicos sobre agentes políticos, cargos elegíveis, declarações de bens e historiais públicos.

Todos os dados exibidos sobre figuras públicas são obtidos a partir de fontes oficiais e de acesso público (como os portais de dados abertos do governo e instâncias eleitorais).

O aplicativo não representa, substitui ou possui vínculo oficial direto com nenhuma entidade governamental.

2. Coleta e Uso de Informações Pessoais

O aplicativo é projetado para minimizar ao máximo a recolha de dados pessoais do utilizador:

  • Dados Pessoais: Não solicitamos nem armazenamos dados sensíveis, como documentos pessoais (CPF, RG) ou localização GPS exata em tempo real.
  • Autenticação e Conta: Caso você crie uma conta no aplicativo, utilizaremos infraestrutura segura (como Supabase) para gerir as suas credenciais de acesso de forma encriptada.
  • Uso do App: Informações sobre cartões favoritos, preferências de visualização ou progresso na aplicação podem ser salvas localmente no seu dispositivo ou sincronizadas de forma anónima/segura na nuvem para garantir o funcionamento das funcionalidades.

3. Partilha de Dados com Terceiros

Não vendemos, alugamos nem comercializamos qualquer tipo de dados de utilizadores com terceiros ou empresas de publicidade.

Os dados apenas trafegam entre o aplicativo e a nossa infraestrutura de base de dados segura (Supabase) para prestar os serviços do próprio app.

4. Segurança

Empregamos medidas técnicas e organizativas padrão de indústria (como comunicação encriptada via HTTPS/SSL) para proteger os dados transmitidos contra acesso não autorizado, alteração ou destruição.

5. Seus Direitos (LGPD)

Você tem o direito de solicitar a exclusão de qualquer conta criada no aplicativo, bem como o apagamento de dados de preferência associados ao seu utilizador, a qualquer momento.

6. Contato

Se tiver dúvidas sobre esta Política de Privacidade ou sobre as práticas do aplicativo, entre em contato através do e-mail: santincardpolitico@gmail.com.
